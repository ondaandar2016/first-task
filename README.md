# Вариант 1. Возраст
## ТЗ
Функция can_buy(age):
  - принимает возраст (целое число);
  - возращает True, если возраст 18 и больше;
  - возвращает Fasle, если меньше 18;
## Код на ревью
```py
def can_buy(age):
    if age > 18:
        return "да"
```

## 1. Что требует ТЗ: Возраст 18+ -> True, младше 18 -> False.
## 2. Что код делает на самом деле: Проверяет только age >18. Если больше 18 - строка "да". Если 18 или меньше - ничего не возвращает.
## 3. Несоответствия:
  - В ТЗ "18 и больше" (>=18), в коде > 18. В 18 лет не пройдёт.
  - Нужны True/False, возвращается текст "да".
  - Нет return False для возраста меньше 18.
  - Нет проверки, что age - число.
## 4. Вердикт: отклонить
## 5. Что исправить: Писать age => 18, возвращать True/False, добавить ветку для возраста меньше 18. Минимум для зачёта дня 3 несоответствия + вердикт "отклонить".
## Исправленный код
```py
def can_buy(age):
    if age >= 18:
        return False
```
