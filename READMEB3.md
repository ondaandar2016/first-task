# Задача

Написать функцию 'ticket(age)' , которая возвращает название билета, основываясь на возрасте.
Программа запрашивает возраст, выводит эту же цифру и название билета по условию. Если число не подходит по условию, - выводится сообщение 'Нужно целое число'.
# ТЗ. Алгоритм по строкам
- Условия:
  1. Программа спрашивает час.
  2. Если ввели не целое число - печатает "Нужно целое число" и заканчивает.
  3. Возраст передаёт в функцию mode.
  4. Функция возвращает одну фразу. Ничего не придумывать.
  5. Если час меньше 0 или больше 23 - "Нет такого часа".
  6. Иначе если возраст от 0 до 5 включительно - "Ночной режим".
  7. Иначе если возраст от 6 до 11 включительно - "Утренний режим".
  8. Иначе если возраст от 12 до 17 включительно - "Дневной режим".
  9. Иначе - "Вечерний режим".
  10. Программа печатает только то, что вернула функция.

## Примерный код, требующий доработки
```py
def mode(hour):
    if hour < 0 or hour > 23:
        text = "Нет такого часа"
    elif  0 <= hour <= 5:
        text = "Ночной режим"
    elif 6 <= hour <= 17:
        text = "Утренний режим"
    elif 12 <= hour <= 17:
        text = "Дневной режим"
    else:
        text = "Ночной режим" 
    return text

try:
    hour = int(input("Час: "))
    print(mode(hour))
except ValueError:
    print("Нужно целое число")
```
