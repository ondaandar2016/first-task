# Вариант 4. Оценка
## ТЗ
Функция is_pass(score):
  - принимает баллы (число);
  - возвращает True, если баллов 60 и больше;
  - возвращает False, если меньше 60.
## Код на ревью
```py
def is_pass(score):
    if score >= 60:
        print ("зачёт")
```

## 1. Что требует ТЗ: Возраст 18+ -> True, младше 18 -> False.
## 2. Что код делает на самом деле: Функция принимает аргумент score — количество баллов за экзамен/тест. Проверяет, больше или равно ли количество баллов 60. 
Если баллов 60 или больше, функция выводит на экран текст "зачёт". Если баллов меньше 60, функция не выводит ничего и завершается без явного возврата возвращает None.
## 3. Несоответствия:
  is_pass должно возвращать True/False, а функция ничего не возвращает (None).
  При баллах меньше 60 функция ничего не выводит, хотя должна.
  Функция выводит текст на экран, но не возвращает результат для использования в коде.
  Не проверяется, что score — число, и что баллы в диапазоне 0-100.
  Функция работает с score >= 60, но не проверяет максимальный балл.
  Отсутствует описание функции, параметров и возвращаемого значения.
## 4. Вердикт: отклонить
## 5. Что исправить: Добавить вывод "незачёт" для баллов меньше 60.
## Исправленный код
```py
def is_pass(score):
    if score >= 60:
        print("зачёт")
    else:
        print("незачёт")
```
