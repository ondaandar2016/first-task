# Вариант 5. Температура
## ТЗ
Функция need_jacket(temp):
  - принимает температуру воздуха;
  - возращает True, если температура ниже 10;
  - возвращает Fasle, если 10 и выше;
## Код на ревью
```py
def need_jacket(temp):
    if temp > 18:
        return False
```

## 1. Что требует ТЗ: Если температура ниже 10 -> True, Если 10 и выше -> False.
## 2. Что код делает на самом деле: Функция принимает аргумент temp (температура воздуха). Проверяет, больше ли температура 18 градусов (строго больше). Если температура равна 18, условие temp > 18 не выполняется (потому что 18 не больше 18), и функция ничего не возвращает (возвращает None). Если температура меньше 18, условие также не выполняется, и функция возвращает None.
## 3. Несоответствия: 
  - Функция возвращает False только когда температура выше 18. При температуре 18 и ниже функция ничего не возвращает.
  - Используется temp > 18 (строго больше). При температуре ровно 18 функция не срабатывает.
  - Функция не проверяет, что temp — это число. Если передать строку: need_jacket("abc") — программа упадёт с ошибкой.
## 4. Вердикт: отклонить
## 5. Что исправить: Добавить возврат True для случаев, когда температура 18 или ниже. Добавить условие return True if temp <= 18 else False.
## Исправленный код:
```py
def need_jacket(temp):
    if temp <= 18:
        return True
    else:          
        return False
```
