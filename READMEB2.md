# Задача

Написать функцию 'rub_word(n)' , которая возвращает правильную форму слова "рубль" для целого числа 'n'.
Программа запрашивает сумму, выводит число и слово через пробел. Если ввод не является целым числом - выводится сообщение 'Нужно целое число'.
# ТЗ. Алгоритм по строкам
- Условия:
  1. Программа спрашивает возраст.
  2. Если ввели не целое число - печатает "Нужно целое число" и заканчивает.
  3. Возраст передаёт в функцию ticket.
  4. Функция возвращает одну фразу из списка ниже. Ничего не придумать.
  5. Если возраст меньше 0 или больше 120 - "Возраст не подходит".
  6. Иначе если возраст от 0 до 6 включительно - "Бесплатно".
  7. Иначе если возраст от 7 до 17 включительно - Детский билет".
  8. Иначе если возраст от 18 до 64 включительно - "Обычный билет".
  9. Иначе - "Льготный билет".
  10. Программа печатает только то, что вернула функция.
  11. Примеры, которые программа обязана повторить один в один:

# Правильный код
```py
def ticket(age):
    
    if age < 0 or age > 120:
        kind = "Возраст не подходит"  
    elif age <= 6:
        kind = "Бесплатно"            
    elif age <= 17:
        kind = "Детский билет"        
    elif age <= 64:
        kind = "Обычный билет"        
    else:  # age >= 65
        kind = "Льготный билет"       
    
    return kind 
try:
    age = int(input("Возраст: "))
    print(ticket(age))
except ValueError:
    print("Нужно целое число")
```
