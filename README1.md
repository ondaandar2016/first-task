# Вариант 2. Пароль
## ТЗ
Функция is_strong(password):
  - принимает строку пароля;
  - возвращает True, если длина пароля не меньше 8 символов;
  - возвращает False, если короче 8.

##  Код на ревью
```py
def is_strong(password):
    if len(password) > 8:
        return True
```
## 1. Что требует ТЗ: Пароль не меньше 8 символов -> True, если меньше 8 -> False.
## 2. Что код делает на самом деле: Проверяет только age >18. Если больше 18 - строка "да". Если 18 или меньше - ничего не возвращает.
## 3. Несоответствия:
  - Функция принимает строку password и вычисляет её длину с помощью встроенной функции len().
  - Функция проверяет условие: len(password) > 8. Это значит, что она проверяет, больше ли длина пароля, чем 8 символов.
  - Если длина пароля строго больше 8 (9, 10, 11 и т.д.), функция возвращает True.
  - Если длина пароля равна 8, условие > 8 не выполняется (потому что 8 не больше 8), и функция не попадает в блок if.
  - Если длина пароля меньше 8 (0, 1, 2, ..., 7), условие также не выполняется, и функция не попадает в блок if.
  - В обоих случаях функция завершается без явного возврата, что в Python эквивалентно возврату None.
## 4. Вердикт: отклонить
## 5. Что исправить: Изменить оператор сравнения с > на >=. Добавить возврат False, когда условие не выполняется.
## Исправленный код
```py
def is_strong(password):
    if len(password) >= 8:
        return True
    else:
        return False
```
