# Задача

Написать функцию 'rub_word(n)' , которая возвращает правильную форму слова "рубль" для целого числа 'n'.
Программа запрашивает сумму, выводит число и слово через пробел. Если ввод не является целым числом - выводится сообщение 'Нужно целое число'.
# ТЗ. Алгоритм по строкам
- Условия:
  1. Программа спрашивает сумму.
  2. Если ввели не целое число - печатает "Нужно целое число" и заканчивает.
  3. Считывает last_two: остаток от деления суммы на 100.
  4. Считывает last_one: остаток от деления суммы на 10.
  5. Если last_two от 11 до 14 включительно - слово "рублей".
  6. Иначе last_one равен 1 - слово "рубль".
  7. Иначе last_two равен 2 или 3 или 4 - слово "рубль".
  8. Иначе слово "рублей".
  9. Печатает число и слово через пробел.
  10. Примеры, которые программа обязана повторить один в один:

# Правильный код
```py
def rub_word(n):
    last_two = n % 100
    last_one = n % 10
    
    if 11 <= last_two <= 14:
        word = "рублей"
    elif last_one == 1:
        word = "рубль"
    elif 2 <= last_one <= 4:
        word = "рубля"
    else:
        word = "рублей"
    
    return word

try:
    money = int(input("Сумма: "))
    print(money, rub_word(money))
except ValueError:
    print("Нужно целое число")
```
