У вас попытки открыть дверь. Код сейфа в программе уже есть: 421.
Сдать: программа + ревью с тем же текстом консоли.

## Правила одним взглядом
Правильный код — 421.
Попыток три.
Угадал — «Открыт» и выход.
Не угадал — «Осталось: N».
Попытки кончились — «Закрыт». Больше не спрашивать.

# Т3. Алгоритм по строкам
01 Секрет лежит в переменной secret и равен 421.
02 Попыток сначала 3.
03 Пока попытки больше 0 — спрашивают код.
04 Если ввод совпал с секретом — печатают Открыт и выходят.
05 Если не совпал — попыток становится на одну меньше.
06 Если после этого попыток 0 — печатают Закрыт.
07 Если попытки ещё есть — печатают Осталось: и число.
08 Код сравнивают как строку. Не превращать в int.
09 Прогоны ниже — эталон консоли.

| Что вводим |	Что видно в консоли |

| 421	       |Код: 421            |
|      	       |Открыт              |
|------------|----------------------|
|111         |Код: 111	            |
|421         |Осталось: 2	        |
|            |Код: 421
|111         |Открыт	            |
|------------|----------------------|
|000         |Код: 421              |
|111         |Осталось: 2           |
|222         |Код: 111              |
|            |Осталось: 1           |

|            |Закрыт	            |

## Рабочий код
```py
secret = "421"
tries = 3
while tries > 0:
    code = input("Код: ")
    if code == secret:
        print("Правильный ответ")
        break
    tries = tries - 1
    if tries == 0:
        print("Закрыт")
    else:
        print("Осталось:", tries)
```
