# Вариант 3. Скидка
## ТЗ
Функция final_price(price):
  - принимает цену (число);
  - если цена 1000 и больше - вернуть цену со скидкой 10%;
  - если цена меньше 1000 - вернуть цену без изменений.
## Код на ревью
```py
def final_price(price):
    if price > 1000:
        return price - 10
```
## 1. Что требует ТЗ: Если цена 1000 и больше -> True, если цена меньше 1000 -> False.
## 2. Что код делает на самом деле: Проверяет, больше ли цена 1000. Если цена строго больше 1000, функция возвращает цену со скидкой 10. Если цена равна 1000, условие price > 1000 не выполняется, и функция ничего не возвращает.
## 3. Несоответствия:
  - Функция принимает строку password и вычисляет её длину с помощью встроенной функции len().
  - Функция проверяет условие: len(password) > 8. Это значит, что она проверяет, больше ли длина пароля, чем 8 символов.
  - Если длина пароля строго больше 8 (9, 10, 11 и т.д.), функция возвращает True.
  - Если длина пароля равна 8, условие > 8 не выполняется (потому что 8 не больше 8), и функция не попадает в блок if.
  - Если длина пароля меньше 8 (0, 1, 2, ..., 7), условие также не выполняется, и функция не попадает в блок if.
  - В обоих случаях функция завершается без явного возврата, что в Python эквивалентно возврату None.
## 4. Вердикт: отклонить
## 5. Что исправить: Изменить условие с > на >=, чтобы скидка применялась при цене 1000 и выше. Добавить возврат исходной цены в else, чтобы функция всегда возвращала число.
## Исправленный код
```py
def final_price(price):
    if price >= 1000:
        return price - 10
    else:
        return price
```
